What: a deterministic skill-server

A local MCP server that enforces engineering standards instead of simply exposing tools.

MCP in 60 seconds

The Model Context Protocol: a standard way for AI coding agents to call tools, read resources, and load prompts.
  • Tools: functions the agent can invoke (validate, scaffold, search)
  • Resources: data the agent can read (pix:// skill indexes, summaries)
  • Prompts: ready-made workflows the agent can start from
  • Transport: stdio (default) or HTTP+SSE — the same server behind every agent
Audience may know little about MCP/agentic: keep this definitional, no jargon. Bridge: "an MCP server can also NOT call an LLM — that is the deterministic trick."

The deterministic control engine

Deterministic validation + safeguards: the server never calls an LLM, so every answer is the same for every model.
  • BM25 full-text search across all skill content
  • Guardrail engine: 18 shared rules + framework/backend/database/devops checks
  • Gateway: pix_tool_gateway + pix_tool_apply with receipt-based validation
  • Fail-safe: deterministic shutdown / rejection paths — a file that fails checks never lands (dry-run preview first)
Deterministic gateway is the star: prompt → pix_tool_gateway → guardrails → receipt → pix_tool_apply. Fail-safe references the abstract's "automatic fail-safe shutdowns and deterministic validation". Tool names verified live (v1.0.0).

Minimal tool surface

10 dispatcher tools instead of 90 — for clients that cap tool counts, and to cut per-turn token cost.
  • Enabled with PIX_GALAXY_MCP_MINIMAL_TOOLS=1 (off by default) — 10 registered tools, verified live
  • Built for Cursor, GitHub Copilot and other caps on MCP tool counts
  • Same capabilities behind dispatcher/action tools
Minimal surface is a cost lever: fewer tools in context per turn on every model. Verified live: `PIX_GALAXY_MCP_MINIMAL_TOOLS=1 pix-galaxy-mcp tools list` → 10 tools (pix_tool, update, gateway, apply, search, check, scaffold, detect, process_handoff, component).

Live demo — install & doctor

From zero to a working gateway in about one minute.
  1. pnpm add -g pix-galaxy-mcp
  2. pix-galaxy-mcp doctor — health check
  3. pix-galaxy-mcp install --agent all — 23 supported agents
Install + doctor demo (~1 min). Preflight: node >= 20. Docker and daemon/HTTP+SSE modes exist as fallback.
