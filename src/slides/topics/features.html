Cache

A result is reused until a skill it read changes.
  • Key: tool + arguments + the digest of every skill the answer used
  • Editing one skill drops only the entries that depended on it
  • Hit or miss, the answer is the same bytes

Flight Recorder

Every call is recorded locally, on this machine.
  • Calls, cache hits, tokens saved, latency, cost per session
  • /pix-stats: reads the log back
  • Nothing leaves the machine; secrets are redacted

Handoff / Handon

A session ends with a file, not with a lost context.
  • /pix-handoff: commits pending work in atomic commits, writes the handoff
  • /pix-handon: verifies every claim against the repository before trusting it
  • Each claim arrives labeled still true, changed, or unverified

Personas

19 expert roles, one command each.
  • /pix-persona-security asks one role for a run
  • The request decides the depth: audit, audit + review, audit + review + plan
  • The run writes docs/audits, docs/reviews, docs/plans

Areas

11 hubs route free text to the leaf skills.
  • /pix-area-frontend collects the request
  • The hub names the leaf skills and tools to load
  • Leaf skills keep tools, no per-leaf slash

Guardrails

Each skill ships the rules it can prove.
  • /pix-check: reports failures against the routed skills applying all the related guardrails
  • /pix-fix; applies the mechanical fixes for blank lines, braces, ASCII, spelling and all the other guardrails
  • A failed guardrail blocks the write, not the model's turn
