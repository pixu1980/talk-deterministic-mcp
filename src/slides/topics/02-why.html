Why

Vague conventions cannot be enforced. Models drift. Nothing gates the output.
  • Same prompt → different quality per model
  • No measurable “best practice” without a check
  • Server-side rules stay identical for every model

Deterministic = model-agnostic

The agent still calls the model. The server compresses what it reads and gates what it writes.
  • Routing, evidence and guardrails arrive compressed, so the tokens go to the answer
  • The same rules run behind Claude, GPT, Gemini, Llama, Qwen…
  • Local-first: skills on disk
