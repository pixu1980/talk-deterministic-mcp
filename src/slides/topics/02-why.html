Why: control over the slot machine

Vibe coding without rules turns the codebase into a slot machine — the server exists to make output measurable.
Bridge narrative from talk-aidd ("Vibe Coding with Rigor"): this MCP server is the step forward from the aidd operating cycle.

The problem

Vague coding conventions cannot be enforced or measured — and every model interprets them differently.
  • Vague: "UI degna di Apple", "design system", "best practice" — uncheckable, unmeasurable
  • Model drift: same prompt → 4 iterations with one model, 1 with another
  • No quality gate: nothing verifies the output before it lands in the repo
Benchmark evidence: DS4 needed 3-4 user prompts vs Sonnet's 1 for the same prompt. Source: benchmark-evidence §2.1, §3.1.

Deterministic = model-agnostic

The server never calls an LLM — so every model sees the same tools, the same rules, the same answers.
  • No hidden prompt, no vendor lock-in, no per-token cost for the server itself
  • Works behind Claude, GPT, Gemini, DeepSeek, Llama, Qwen — identical behavior
  • Runtime deps: @modelcontextprotocol/sdk + zod only
This is the talk's core claim: enforcement without LLM = deterministic = testable everywhere.

The ~5% claim

The MCP server accounts for roughly 5% of total project cost — model inference is the bottleneck, not tooling.
  • MCP cost < 1% (phonebook) and < 6% (bookmarks) of total billed cost
  • Prompt caching changes the economics: Sonnet wrote ~280K cached tokens → 59-178 input tokens of fresh input for the whole session
  • Estimated caching savings: $30-70 per session
Source: benchmark-evidence §2.2, §2.4, §3.2. Honest framing: measured on cost; effort proxy in tool-result chars.

Honest failures

Not every experiment worked — and the caveats matter as much as the wins.
  • 0/3 models used caveman/tokensave in read mode — even when the prompt asked explicitly
  • GPT "cheated" on architecture (805 LOC monolith); DS4 "cheated" on integration (0 tests, no build, minimal SSRF)
  • No baseline session without the server → the delta is inferred, not measured
Honesty is a stated goal of the talk (abstract: "deep, honest technical analysis ... and failed experiments").
