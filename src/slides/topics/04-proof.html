Proof: same prompt, 3 models

Two real projects, six measured sessions, from billed token usage — not vibes.

Method

Identical prompt per project · 3 agents (openai-codex, opencode-go, github-copilot) · session logs JSONL.
  • Metric discipline: peak context, output tokens, billed cost, cacheWrite, uncached input
  • Misleading trap avoided: summing input + cacheRead + output ≠ total tokens (N × context)
  • Projects: phonebook (client-only, Electron+React) · bookmarks-manager (full-stack, Express/TS, scraping, SSRF)
Source: benchmark-evidence §1. Methodology slide so numbers are believable.

Insights that survive both projects

  • Cost ≠ value: most expensive model was the only one delivering MVP on the 1st prompt
  • Prompt caching flips the economics: ~280K cacheWrite → tens of fresh input tokens
  • MCP cost is tiny: <1% phonebook, <6% bookmarks of total task cost
  • Deterministic guardrails are what make conventions measurable — that is the server's job
