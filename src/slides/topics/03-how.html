One config shape

The same server.json / mcp.json contract every agent consumes. 
      
{
  "mcpServers": {
    "pix-galaxy-mcp": {
      "command": "pix-galaxy-mcp",
      "args": ["serve"],
      "transport": "stdio"
    }
  }
}
Minimal mode: PIX_GALAXY_MCP_MINIMAL_TOOLS=1 — 10 dispatcher tools instead of 90.
Config lives in server.json (registry metadata) and mcp.json (per-agent). Minimal mode targets Cursor/Copilot caps.

The deterministic gateway

Single entry point: route the prompt, validate the code, return a receipt. A file that fails guardrails never lands — fail-safe before write.

Receipt, not opinion

Validation is a token you can show, not a claim you repeat. 
      
{
  "file": "src/components/BookmarkCard.tsx",
  "guardrails": ["a11y", "naming", "structure"],
  "allPass": true,
  "receipt": "pk_gw_a1b2c3…",
  "hash": "sha256:9f8e…",
  "dryRun": true
}
A file that fails checks never lands — fail-safe before write, preview first.
Based on gateway/apply semantics from README + gateway.test.mjs. Exact JSON shape is illustrative — verify against the live tool before the talk.

Guardrail engine

Testable assertions instead of vague conventions.
  • 18 shared rules: a11y, naming, validation, structure
  • Framework-specific: backend (security, API design), data, devops
  • Runs before write — the model cannot ship a file that fails the checks
Source: README (guardrail engine, enforcement). More in docs/03-engineering-guides.md.

Ops: install, daemon, docker

One package, many deployment shapes — model-agnostic everywhere.
  • Installer: install --agent all — 23 supported agents, self-healing scripts
  • Doctor: health check for config, skills, transports
  • Daemon / HTTP+SSE: long-running server for Pi and VS Code
  • Docker: containerized server with TLS cert generation
  • Fail-safe: deterministic shutdown paths guarded by tests
Source: README (CLI reference, daemon & services, Docker). Fail-safe shutdown demo is part of the "safeguards" the abstract promises.

Live demo — gateway check/apply

  1. Call pix_gateway with a component draft
  2. Review guardrail results — fix until allPass: true
  3. pix_apply dry-run to preview the write
