Wrapping up

What the 6 measured sessions actually taught us.

Works

  • Deterministic server = model-agnostic enforcement
  • MCP cost < 1-6% of the task — inference is the bottleneck
  • Prompt caching flips the economics ($30-70 saved)
  • 1 prompt → MVP when the model reads the skills

Doesn’t

  • More tool calls ≠ better output (GPT: 25-30 calls, weakest result)
  • Cheapest model isn’t cheapest — retries cost developer time
  • 0/3 models adopted caveman/tokensave, even when asked
  • No baseline yet: the server delta is inferred, not measured

Takeaways

  1. Enforcement without LLM is deterministic, testable, and model-agnostic
  2. Skills read early beat tool spam: Sonnet 5 calls + mode:full → 6/6 specs
  3. The server doesn’t replace model quality — it makes conventions measurable
The three takeaways mirror the abstract: deterministic engine, skills-structured output, measurable safeguards.
