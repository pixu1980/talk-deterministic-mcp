# Rehearsal guide

Target duration: 35–40 minutes. These are proposed budgets, not measurements from a performed rehearsal.

| Chapter       | Target | Focus                                             |
| ------------- | -----: | ------------------------------------------------- |
| Introductions |  2 min | Title and speaker                                 |
| What I do     |  3 min | DevX and company context                          |
| The need      |  4 min | Rotation, repeated work and weak prompt contracts |
| Experiments   |  6 min | Method, results, failures and limitations         |

| The solution  | 10 min | Request path, gateway, mechanisms and installer   |

| Contribute    |  2 min | Four contribution paths and repository            |
| Goodbye       |  2 min | Original wrap-up, TAF and thanks                  |

Total target: 38 minutes. No live demo or timed rehearsal is planned, as confirmed by the speaker. The timing above is optional planning context, not a release gate.
